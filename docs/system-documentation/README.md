# PK Document Tracking System - Proposed Documentation

**26 October 2026 | Revision 02 | Proposal**

This documentation defines the proposed processes, information flows and operating procedures for PK Document Tracking System. It presents the intended system operation through process diagrams, decision flows and illustrated user scenarios.

The proposed operation will cover controlled hardcopy and softcopy records, configurable approvals, document access, assignments, physical transfers, disposal, administrative controls, audit and recovery.

The Process Flow presents illustrated responsibilities and activity notes across five subprocesses. The two-sheet DFD shows participants, the central system and labelled information exchanges. The six-sheet Flowchart details authorization, requests, approvals, handoffs, document operations, file access, administration and recovery. Diagram headings, cards, arrows and notes use the Peanut Kisses red theme.

The guide includes nine request scenarios: Create Softcopy, Revise Softcopy, Cancel Softcopy, Create Hardcopy, Update Hardcopy, Document Access Grant, Document Assignment, Hardcopy Transfer and Hardcopy Disposal. Shared procedures explain submission, approval, returns, rejection, eligible draft deletion, dispatch and receipt.

Permitted direct maintenance will be documented separately from those approval requests. Direct Softcopy Dispose and direct assignments will follow their own permissions and record scope. Transfer approval will prepare a handoff; custody will change only after dispatch and recipient acceptance.

Screen illustrations use sample accounts, records, locations and transactions. The sample approval route has two steps; the published workflow will determine the approvers for each request. Available menus and actions will depend on assigned permissions and document access.
